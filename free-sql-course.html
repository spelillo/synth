Learn SQL free: 60 interactive lessons, from your first SELECT to window functions

Synth's Learn SQL courses teach SQL by doing. Each lesson explains one idea, shows a runnable example, and gives you a task on real practice data. Write your query, press Check Answer, and Synth tells you whether it is right and, if not, exactly what is different. Everything runs in your browser, with nothing to install and no account needed to start.

How each lesson works

  1. Read the concept. A short explanation of one SQL idea, with a runnable example.
  2. Write a query. The task asks for a specific result from tables that are already loaded: NFL team stats, a bank statement, grocery sales, a bookstore's authors, books, customers and orders, a company's departments and employees, subscriptions, and monthly sales.
  3. Check your answer. Your result is compared with the expected one. A wrong answer gets specific feedback, such as rows missing, an extra duplicate, a wrong column, or rows grouped incorrectly.
  4. Get unstuck. Three hints per lesson, a solution that unlocks after two attempts, and an AI tutor (free sign-in) that explains your mistake without just giving the answer away.

Progress saves in your browser automatically. Sign in for free to keep it in sync across devices.

Frequently asked questions

Is this SQL course really free?

Yes. All 60 lessons are free and you can start without an account. Progress saves in your browser; a free sign-in syncs it across devices and unlocks the AI tutor.

Do I need to install anything?

No. Every lesson runs in your browser on SQLite compiled to WebAssembly, with the practice tables already loaded. There is no database to install or connect to.

How does the answer checking work?

When you press Check Answer, Synth runs your query and compares its result with the expected result. If it is wrong it tells you what is different: missing or extra rows, a wrong column, a value rounded differently, or rows grouped wrongly.

What if I get stuck?

Each lesson has three hints, from a nudge to nearly the answer. The solution unlocks after two attempts or all three hints, and signed-in learners can ask an AI tutor that explains the mistake without simply handing over the answer.

Which SQL dialect does it teach?

The lessons run on SQLite, and the material (SELECT, WHERE, GROUP BY, joins, subqueries, CTEs and window functions) is standard SQL that carries over to PostgreSQL, MySQL, SQL Server, BigQuery and Snowflake. Date functions are the main place dialects differ, since SQLite stores dates as text and uses STRFTIME, DATE and JULIANDAY.

Where do I start?

Start with SQL Foundations if you have never written a query. If you can already write SELECT, WHERE and GROUP BY, jump to Joins & Combining Data, or to Analytics SQL for CASE, CTEs and window functions.
