How to get the top N rows per group in a CSV

The top 3 products in each category, the best sales rep in each region, the latest order for each customer. These all need the top rows inside every group, which is awkward in a spreadsheet and one query in SQL. Synth loads your CSV into a SQLite database in your browser, so you can run it right away. Nothing is installed, and the file never leaves your computer.

The example file

Say you drop a sales.csv like this into Synth. It becomes a table called sales:

rep | region | amount
Ana | East   | 950
Ben | East   | 1200
Cy  | East   | 430
Dee | East   | 1200
Eli | West   | 80
Fay | West   | 2100
Gus | West   | 660
Hal | North  | 300

First, sort numbers as numbers

Synth keeps CSV values as text, and text sorts character by character. This query looks right but returns Ana (950), Eli (80) and Gus (660), because "9" and "8" come after "2" and "1":

SELECT rep, amount
FROM sales
ORDER BY amount DESC
LIMIT 3;

Wrap the column in CAST(... AS REAL) and it returns Fay (2100), Ben (1200) and Dee (1200):

SELECT rep, amount
FROM sales
ORDER BY CAST(amount AS REAL) DESC
LIMIT 3;

Every query below uses the same cast.

Top 2 rows in each region

ROW_NUMBER() numbers the rows inside each group. PARTITION BY region restarts the count for every region, and the outer query keeps the first two:

SELECT region, rep, amount
FROM (
  SELECT region, rep, amount,
         ROW_NUMBER() OVER (
           PARTITION BY region
           ORDER BY CAST(amount AS REAL) DESC
         ) AS rn
  FROM sales
)
WHERE rn <= 2
ORDER BY region, rn;
region | rep | amount
East   | Ben | 1200
East   | Dee | 1200
North  | Hal | 300
West   | Fay | 2100
West   | Gus | 660

Change rn <= 2 to any number. North has only one rep, so it gets one row.

The best row per group, ties included

Ben and Dee tie for first in East. ROW_NUMBER() would pick one of them arbitrarily. RANK() gives both of them rank 1, so keeping rank 1 returns both:

SELECT region, rep, amount
FROM (
  SELECT region, rep, amount,
         RANK() OVER (
           PARTITION BY region
           ORDER BY CAST(amount AS REAL) DESC
         ) AS rnk
  FROM sales
)
WHERE rnk = 1
ORDER BY region;

Show every row's rank

Drop the outer query to see the rank next to each row. Tied rows share a rank and the next rank is skipped, so East goes 1, 1, 3, 4. Use DENSE_RANK() instead if you want 1, 1, 2, 3.

SELECT region, rep, amount,
       RANK() OVER (
         PARTITION BY region
         ORDER BY CAST(amount AS REAL) DESC
       ) AS rank_in_region
FROM sales
ORDER BY region, rank_in_region;
region | rep | amount | rank_in_region
East   | Ben | 1200   | 1
East   | Dee | 1200   | 1
East   | Ana | 950    | 3
East   | Cy  | 430    | 4
North  | Hal | 300    | 1
West   | Fay | 2100   | 1
West   | Gus | 660    | 2
West   | Eli | 80     | 3

Frequently asked questions

How do I get the top N rows per group in a CSV?

Number the rows inside each group with ROW_NUMBER() OVER (PARTITION BY group ORDER BY value DESC), then keep the rows where that number is N or less.

Why does ORDER BY sort my numbers wrong?

Synth keeps CSV values as text, and text sorts character by character, so 950 comes before 1200. Sort by CAST(column AS REAL) to sort them as numbers.

How do I get the single highest row in each group?

Use the same query and keep rank 1. Use RANK() instead of ROW_NUMBER() if you want every row that ties for first place.

What is the difference between ROW_NUMBER and RANK?

ROW_NUMBER gives every row a different number, even when values tie. RANK gives tied rows the same number and skips the next one, so two rows tied for first are both 1 and the next is 3.

Do window functions work in Synth?

Yes. Synth runs SQLite in your browser, which supports ROW_NUMBER, RANK, DENSE_RANK and the other window functions.
