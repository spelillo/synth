How to find blank cells and missing values in a CSV

Before you trust a CSV, it helps to know where it has holes: customers with no email, orders with no date, rows that are empty except for an id. Synth loads your CSV into a SQLite database in your browser, so each of those checks is one query. Nothing is installed, and the file never leaves your computer.

The example file

Say you drop a customers.csv like this into Synth. It becomes a table called customers:

id | name       | email           | phone    | city
1  | Ana Lopez  | ana@acme.com    | 555-0101 | Austin
2  | Ben Okafor |                 | 555-0102 | Denver
3  | Cy Park    | cy@globex.io    | N/A      |
4  |            |                 |          |
5  | Dee Shah   | dee@example.com |          | Austin
6  | Eli Ross   | eli@acme.com    | 555-0106 | Boston

Blank cells are empty text, not NULL

Synth keeps every CSV value as text, and an empty cell becomes an empty string. So WHERE email IS NULL finds nothing here, while WHERE email = '' finds the blanks. Spaces around a value are trimmed when the file loads, so a cell holding only spaces counts as blank too.

Rows where one column is blank

SELECT id, name, email
FROM customers
WHERE email = '';

That returns rows 2 and 4.

Count missing values in every column

Each SUM(column = '') counts the blanks in one column, so one query gives a quick report for the whole file:

SELECT COUNT(*)        AS total_rows,
       SUM(name  = '') AS blank_name,
       SUM(email = '') AS blank_email,
       SUM(phone = '') AS blank_phone,
       SUM(city  = '') AS blank_city
FROM customers;
total_rows | blank_name | blank_email | blank_phone | blank_city
6          | 1          | 2           | 2           | 2

For a percentage instead of a count:

SELECT ROUND(100.0 * SUM(email = '') / COUNT(*), 1) AS pct_blank_email
FROM customers;

Here a third of the rows (33.3%) have no email.

Rows with any blank, or no blanks

List every incomplete row:

SELECT *
FROM customers
WHERE name = '' OR email = '' OR phone = '' OR city = '';

Or keep only the complete ones, rows 1 and 6 here:

SELECT *
FROM customers
WHERE name <> '' AND email <> '' AND phone <> '' AND city <> '';

To drop just the rows that are empty apart from the id, like row 4, and keep everything else:

SELECT *
FROM customers
WHERE NOT (name = '' AND email = '' AND phone = '' AND city = '');

Catch N/A, NULL and other placeholders

Some exports write N/A, NULL or - instead of leaving a cell empty. Those are real text, so = '' misses them. Check for the common ones along with blanks:

SELECT id, name, phone
FROM customers
WHERE lower(phone) IN ('', 'n/a', 'na', 'null', 'none', '-');

That finds row 3's N/A as well as the empty phones in rows 4 and 5.

Fill blanks with a default

NULLIF(city, '') turns a blank into NULL, and COALESCE replaces NULL with the value you give it:

SELECT id, name,
       COALESCE(NULLIF(city, ''), 'Unknown') AS city
FROM customers;

Rows 3 and 4 now show Unknown. Click Download CSV above the results to save the cleaned version. Your original file is not changed.

Frequently asked questions

How do I find blank cells in a CSV column?

Drop the CSV into Synth and run SELECT * FROM table WHERE column = ''. Synth stores an empty cell as empty text, so compare it with '' rather than IS NULL.

Why does IS NULL find nothing?

Synth keeps every CSV value as text, and an empty cell becomes an empty string, not NULL. Use column = '' to find it, or NULLIF(column, '') to turn it into NULL.

How do I count missing values in every column?

Add one SUM(column = '') per column in a single query. Each one counts the blank cells in that column.

Do cells with only spaces count as blank?

Yes. Synth trims spaces around each value when it loads the file, so a cell with only spaces becomes empty text too.

What about N/A or NULL written as text?

Those are real text values, so = '' won't catch them. Check for them with lower(column) IN ('', 'n/a', 'na', 'null', 'none', '-').
