How to make a pivot table from a CSV with SQL

A pivot table answers questions like "how much did each category sell, by month?" You can get the same answer from a CSV with a few lines of SQL, and SQL keeps working when the file is too slow or messy for a spreadsheet. Synth runs these queries in your browser, with nothing to install and without uploading your file.

The examples below use a table called sales with the columns order_date, region, category and amount. Swap in your own column names.

Step 1: Load the CSV

Open Synth and drop your CSV onto the page. It becomes a SQLite table named after the file, so sales.csv becomes sales. No account is needed.

Step 2: Totals by one field

The simplest pivot puts one field in rows and sums a number. In SQL that's a GROUP BY:

SELECT category,
       SUM(amount) AS total
FROM sales
GROUP BY category
ORDER BY total DESC;

Step 3: Two fields in rows

Add more fields to the GROUP BY to nest them, the way a pivot table stacks row labels. You can show several values at once, like a sum and a count:

SELECT region, category,
       SUM(amount) AS total,
       COUNT(*)    AS orders
FROM sales
GROUP BY region, category
ORDER BY region, total DESC;

Step 4: Put values across the top as columns

This is the part people usually mean by "pivot." SQLite has no PIVOT keyword, so each column is a SUM(CASE WHEN ...) that only adds rows matching that column. Here months go across the top:

SELECT category,
       SUM(CASE WHEN strftime('%m', order_date) = '01' THEN amount ELSE 0 END) AS jan,
       SUM(CASE WHEN strftime('%m', order_date) = '02' THEN amount ELSE 0 END) AS feb,
       SUM(CASE WHEN strftime('%m', order_date) = '03' THEN amount ELSE 0 END) AS mar,
       SUM(amount) AS total
FROM sales
GROUP BY category
ORDER BY total DESC;

strftime('%m', order_date) pulls the month out of a date stored like 2026-01-15. If your dates look different, ask Synth's AI assistant to convert them, or pivot on a text column such as region instead.

Step 5: Percent of total

A window function divides each group by the grand total, like "Show values as % of grand total" in a spreadsheet:

SELECT category,
       SUM(amount) AS total,
       ROUND(100.0 * SUM(amount) / SUM(SUM(amount)) OVER (), 1) AS pct_of_total
FROM sales
GROUP BY category
ORDER BY total DESC;

Step 6: Add a grand total row

SELECT 'All categories' AS category, SUM(amount) AS total FROM sales
UNION ALL
SELECT category, SUM(amount) FROM sales GROUP BY category;

Frequently asked questions

Can you make a pivot table with SQL?

Yes. Group by the row field and use SUM(CASE WHEN column = 'value' THEN amount ELSE 0 END) for each column you want across the top. That is how a pivot works in SQLite, which has no PIVOT keyword.

How do I sum values by category in a CSV?

SELECT category, SUM(amount) AS total FROM my_table GROUP BY category ORDER BY total DESC. This is the SQL equivalent of a one-field pivot table.

How do I put months as columns?

Extract the month with strftime('%Y-%m', date) and write one SUM(CASE WHEN ...) per month. Each CASE becomes a column in the result.

How do I show percent of total?

Divide each group's total by the grand total using a window function: ROUND(100.0 * SUM(amount) / SUM(SUM(amount)) OVER (), 1).

Do I need Excel or a database for this?

No. Synth loads the CSV into a SQLite database inside your browser tab. Nothing is installed and the file is not uploaded unless you sign in and choose to save it.
