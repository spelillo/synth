About

Query any CSV file with SQL — no database required.

Synth turns a CSV file into a real, queryable SQLite database, running entirely in your browser tab. Write actual SQL, or just ask in plain English.

What Synth is

Synth instantly queries any CSV file with real SQL, or plain-English questions. Upload a file and it loads into an actual SQLite database running in your browser tab — no server-side database, no waiting on uploads, nothing to install.

Local-first, by default

Lite Mode never touches a server — your file, your query, your browser, nothing else. Sign in with Normal Mode only if you want workspaces and chat sessions saved to the cloud so you can pick them up from another device.

SQL or plain English

Write SQL yourself, or ask the built-in AI assistant. Switch anytime between SQL Mode (get a runnable query back) and General Mode (get a plain-English answer instead). Synth is built for two different people: someone who knows SQL and doesn't want to spin up a server for one file, and someone who'd rather skip SQL entirely and just ask a question.

Why it exists

Querying a single CSV file usually means one of two bad options: wrestling the data into Excel formulas that don't scale past a few thousand rows, or standing up an entire database server to ask five questions of one file. Synth is the missing middle — real SQL, zero setup, for exactly that use case.
